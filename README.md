# FMCG-Analysis-dashboard-
🛒 FMCG Sales Dashboard (Power BI)
📌 Project Overview

This project presents an interactive FMCG Sales Dashboard built using Power BI.
The dashboard provides detailed insights into sales performance, product contribution, store performance, and profitability metrics.

It helps business stakeholders analyze trends, identify top-performing SKUs, and make data-driven decisions.
